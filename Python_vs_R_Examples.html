Pandas Equivalent: dplyr from tidyverse

Used for data wrangling. Example: Filtering a dataset.

# Python

import pandas as pd
data = pd.DataFrame({'age': [23, 45, 12, 56,70 ], 'Injury Severity Score': [87, 56, 30, 77,80]})

But can also use tidymodels (notice the similar set up to Scikit-learn in a pipeline style with algorithm definition, data definition and model fitting)

library(tidymodels)

lm_model <- linear_reg() %>% 
            set_engine('lm') %>% # adds lm implementation of linear regression
            set_mode('regression')


lm_fit <- lm_model %>% 
          fit(score ~ age, data)


lm_fit[["fit"]][["coefficients"]]

Seaborn Equivalent: ggplot2

Used for plotting Example: Scatter plot

# Python
import seaborn as sns
import matplotlib.pyplot as plt

sns.scatterplot(x = data["age"], y = data["Injury Severity Score"])

plt.show()
# R


library(ggplot2)

ggplot(data, aes(x = age, y = score)) +
  geom_point()

Numpy Equivalent: base

Example: Dot product

# Python
import numpy as np
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
dot_product = np.dot(a, b)
# R
a <- c(1, 2, 3)
b <- c(4, 5, 6)
dot_product <- sum(a * b)

### **`Scikit-learn` Equivalent:  `tidymodels`**

Used for machine learning pipelines

Example: Fitting a linear regression algorithm

```{python}
from sklearn.linear_model import LinearRegression

model = LinearRegression()
X = data[["age"]]  # must be 2D
y = data["Injury Severity Score"]  # 1D target


model.fit(X, y)
print(model.intercept_, model.coef_)
```

In R you have previously (Module 2) fitted linear regression algorithms using the `stats` package (part of `base` R) with the functions `glm` and `lm`

```{r, message=FALSE, warning=FALSE}
# R


model <- lm(score ~ age, data = data)
```

But can also use `tidymodels` (notice the similar set up to Scikit-learn in a *pipeline* style with algorithm definition, data definition and  model fitting) 

```{r, message=FALSE, warning=FALSE}

library(tidymodels)

lm_model <- linear_reg() %>% 
            set_engine('lm') %>% # adds lm implementation of linear regression
            set_mode('regression')


lm_fit <- lm_model %>% 
          fit(score ~ age, data)


lm_fit[["fit"]][["coefficients"]]
```
